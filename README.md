# IIT Campus Student Management System

A Python command-line system to enroll students, update records and track attendance.

Built for the **Introduction to Programming Principles** module at IIT Campus.

## Features

- Enroll new students with input validation (Student ID, NIC, phone number, name lengths)
- View a single student's details by Student ID
- View all students in a branch (centre)
- Update student details
- Mark attendance by centre and tutorial group
- View a student's attendance for a date range

## Tech Stack

- Python 3
- No external libraries

## How to Run

1. Make sure Python 3 is installed.
2. Clone the repository:
   ```
   git clone https://github.com/Raiqa-Abdul-Qadir/student-management-system.git
   cd student-management-system
   ```
3. Run the program:
   ```
   python student_management_system.py
   ```
4. Choose an option from the menu (1–7).

## Notes

Data is stored in memory, so records are cleared when the program exits.
